## 1. Introduction

| Detail           | Information                                                        |
| ---------------- | ------------------------------------------------------------------ |
| **Founded**      | 1999                                                               |
| **Founders**     | Marc Benioff, Parker Harris, Dave Moellenhoff, Frank Domingues     |
| **Headquarters** | San Francisco, California                                          |
| **Model**        | Software-as-a-Service (SaaS)                                       |
| **Known for**    | Pioneering cloud-based enterprise software                         |

Salesforce **pioneered the SaaS model**. Businesses could use powerful software through a web browser instead of installing it on local servers. Today it serves hundreds of thousands of organizations across nearly every industry.

## 2. What Is CRM?

**Customer Relationship Management** is the practice of managing a company's interactions with current and potential customers.

A CRM system keeps all customer data in one place:

- 📇 Contact details
- 🛒 Purchase history
- 🎫 Support tickets
- 💬 Communication records

> 💡 **Why it matters:** When sales, marketing, and service teams all work from the same data, they make better decisions and build stronger customer relationships.

## 3. Core Products

Salesforce organizes its offerings into **"Clouds,"** each focused on a particular business function.

| Product              | Purpose                                                   |
| -------------------- | --------------------------------------------------------- |
| **Sales Cloud**      | Manage leads, opportunities, and sales forecasts          |
| **Service Cloud**    | Case management and omnichannel customer support          |
| **Marketing Cloud**  | Personalized campaigns and customer journeys              |
| **Commerce Cloud**   | Online storefronts for B2C and B2B businesses             |
| **Experience Cloud** | Portals for customers, partners, and employees            |
| **Tableau**          | Data visualization and business intelligence              |
| **Slack**            | Team collaboration connected to CRM data (acquired 2021)  |

## 4. The Salesforce Platform

Beyond its ready-made apps, Salesforce offers a platform for customization and development.

### 🖱️ No-Code / Low-Code Tools

- **Flow Builder**: automates business processes visually
- **Object Manager**: creates custom objects, fields, and relationships
- **Lightning App Builder**: designs pages with drag-and-drop

### 👩‍💻 Developer Tools

| Tool                             | Description                                         |
| -------------------------------- | --------------------------------------------------- |
| **Apex**                         | Object-oriented programming language similar to Java |
| **Lightning Web Components**     | Modern UI framework built on web standards          |
| **SOQL / SOSL**                  | Query languages for retrieving Salesforce data      |

### 🧩 AppExchange

A marketplace of **thousands of third-party apps** and integrations that extend what Salesforce can do.

## 5. Artificial Intelligence

Salesforce has invested heavily in AI:

- **Einstein**: predictive analytics, lead scoring, and smart recommendations
- **Agentforce**: autonomous AI agents that resolve customer inquiries, qualify leads, and carry out multi-step tasks, grounded in a company's own trusted data
